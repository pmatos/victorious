# Music is masked by an ONNX audio tagger, not a torch model

Emote and lobby music is silenced before transcription, so Whisper cannot read it as lyrics. The tagger is YAMNet (AudioSet, 521 classes) converted to ONNX and run with `onnxruntime`, which faster-whisper already depends on, so the default install gains a 16 MB model and no torch. This amends ADR 0001, which assumed audio tagging pulls in torch: torch arrives with diarization, not here. We chose to cut speech spans at the masked seconds and silence them before Whisper, rather than dropping transcripts after the fact, so music never reaches the decoder while the voice activity detector still sees the original audio and output outside masks does not move; the rule is per second (music-dominant and no speech) so speech over music is kept; vocal music that the tagger labels as speech is therefore still transcribed, which acceptance on labelled Recordings will revisit. The model comes from a pinned revision of a third-party conversion on Hugging Face, so a vanished repository fails loudly and `--no-speech` still works.
